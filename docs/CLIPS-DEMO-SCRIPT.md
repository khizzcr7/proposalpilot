# ProposalPilot — Clips demo script (public recording, no login)

Target length: 2-3 minutes. Record the live demo in a browser, no login,
no API key. Speak the lines below or use captions; show the screen, not
your face.

## Shot list
1. (0:00-0:20) Live demo homepage. Say: "ProposalPilot is an agent-native
   copilot for freelance proposals. Paste a job post, and one shared set of
   actions does the first pass."
2. (0:20-0:50) Click the "React + Node API integration" sample, then "Run
   the agent". Show the Agent trace panel filling with the three real action
   calls: extractJobDetails, scoreFit, draftProposal.
3. (0:50-1:20) Scroll the results: extracted title, budget $35-$50/hr,
   remote yes, skills named; then the fit score with its breakdown, and the
   matched vs not-in-profile skills.
4. (1:20-1:50) Edit one line of the draft, click "Save to pipeline", then
   "Mark Ready" in the pipeline. Show the draft saved under its title.
5. (1:50-2:20) Open the "Actions and API view" section and point at the
   action definitions and their schemas: "One defineAction per capability.
   The UI, the agent trace and this API view all read the same definitions."
6. (2:20-2:40) Switch to the second sample, the vague post with red flags,
   run the agent again, and show the lower score and the red flags. Say:
   "It also tells you when to walk away, and it never claims a skill that
   is not in the profile."
7. (2:40-end) Closing line on screen: "ProposalPilot. Built with
   Agent-Native defineAction. Try it live at [live demo URL]."

## Recording notes
- Record at 1080p, browser window maximised, no personal inboxes or tabs
  visible.
- The recording itself must be public and viewable without a login: use
  Builder.io Clips (the hackathon's own tool) or any public video host that
  plays without sign-in, and paste that URL in the submission form.
- Do NOT include any email address, password, token or personal document
  in the recording.
